# **GhostHand**

#### Allows you to interact through entities.

!!! Danger "Blatant"

    This is considered a cheat and may not bypass advanced anticheats.

!!! Tip

    AutoClicker modules in certain clients may break with this, if so you should whitelist swords/weapons in that specific client, and then ensure you don't have those items whitelisted in this module.

---

## Transparent

### Always

If you're able to interact through a player, they will be semi-transparent.

### None

Players will not be semi-transparent even if you're able to interact through them.

!!! Note

    This does not apply to any other entities.

## Use item whitelist

Uses the item whitelist that can be changed below, which means **GhostHand** will only activate when you are holding whitelisted items.

## Use block whitelist

Uses the block whitelist that can be changed below, which means **GhostHand** will only activate when you are attempting to break a block that is whitelisted.

## Bedwars only

Only activates if you are currently in a Bedwars game.

## Through teammates

Will allow you to interact through players that are considered teammates, which depends on the [Teams Module](../../../modules/meowtils/teams/).

## Through enemies

Will allow you to interact through players that are also not on your team.

!!! Info

    This automatically excludes players that are bots, which is based on [Teams Module](../../../modules/meowtils/teams/).

## Through armorstands

Will allow you to interact through armorstands.

## Item whitelist

### Swords

If enabled, **GhostHand** is able to activate while holding swords.

### Tools

If enabled, **GhostHand** is able to activate while holding any items considered tools.

**Applies to:**

- Pickaxes

- Axes

- Shovels

- Shears

### Hand

If enabled, **GhostHand** is able to activate while you aren't holding any items.

### Blocks

If enabled, **GhostHand** is able to activate while you are holding any block.

!!! Tip

    This can be used to place cobwebs directly on players, amongst other things.

### Buckets

If enabled, **GhostHand** is able to activate while you are holding bucket items.

**Applies to:**

- Bucket

- Water bucket

- Lava bucket

!!! Tip

    This can be used to place liquids directly on players.

### Flint and steel

If enabled, **GhostHand** is able to activate while you are holding flint and steel.

!!! Tip

    This can be used to light fires directly on players.

## Block whitelist

### Beds

Will allow you to interact with beds through selected entities.

### Obsidian

Will allow you to interact with obsidian through selected entities.

### Defense blocks

Will allow you to interact with blocks that are considered Bedwars defense blocks through selected entities.

**Applies to:**

- Wool

- Wood

- Clay

- Ice

- Glass

- Endstone

### Chests

Will allow you to interact with chests through selected entities.

**Applies to:**

- Chests

- Ender Chests
