# Settings

General client settings. This module stays enabled.

---

## Auto-Updates

On by default. New GitHub releases from [brrock/meowtils-modern](https://github.com/brrock/meowtils-modern) are downloaded and applied on the next launch.

If you turn it off, chat only shows a download link. More detail: [Auto Updates](../../other/auto-updates.md).

## Smooth font

Use the original Meowtils TTF for HUD and world text. Off uses vanilla Minecraft font. The Click GUI always uses the TTF.

## Copy chat

Copy the hovered chat line with right-click (also middle-click and Ctrl+C). Chat overlay mods can still steal the click.

## Prefix

**Modes:** Default, Myau, Fire, Nebula, Air, Custom, Short

`/theme` sets colors for Custom and Short.

### Lowercase

Makes prefix letters lowercase.

## Preview

Sends a prefixed chat line so you can see the current theme.
