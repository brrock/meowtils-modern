# **UpgradeHUD**

#### Displays team upgrades on screen.

---

## Text color

Changes the color for the HUD text.

## Scale

Changes size of the HUD.

## Short names

Shortens the names of the upgrade name.

**Applies to:**

- Sharpness → Sharp

- Protection → Prot

- Feather Falling → Feather

- Heal Pool → Heal

## Show Sharpness

Will show current sharpness level.

**Missing:** <span style="color: #ff5555">✗</span>

**Level:** <span style="color: #55ff55">1 - 2</span>

## Show Protection

Will show current protection level on armor.

**Missing:** <span style="color: #ff5555">✗</span>

**Level:** <span style="color: #55ff55">1 - 4</span>

## Show Traps

Will show current trap, if trap is triggered it will show the next queued trap, if your team has any.

**Missing:** <span style="color: #ff5555">✗</span>

**Traps:** <span style="color: #55ff55">Miner Fatigue</span>, <span style="color: #55ff55">Blindess</span>, <span style="color: #55ff55">Reveal</span>, <span style="color: #55ff55">Counter-Offensive</span>

## Show Feather Falling

Will show current feather falling level on boots.

**Missing:** <span style="color: #ff5555">✗</span>

**Level:** <span style="color: #55ff55">1 - 2</span>

## Show Heal Pool

**Missing:** <span style="color: #ff5555">✗</span>

**Unlocked:** <span style="color: #55ff55">✓</span>

## Show Forge

Will show current forge type.

**Missing:** <span style="color: #ff5555">✗</span>

**Types:** <span style="color: #aaaaaa">Iron</span>, <span style="color: #ffaa00">Golden</span>, <span style="color: #00aa00">Emerald</span>, <span style="color: #aa0000">Molten</span>
