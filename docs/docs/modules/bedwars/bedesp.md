# **BedESP**

#### Renders an ESP for beds & obsidian.

---

## Color

Changes the color of the ESP box.

!!! Note

    This only applies to beds, obsidian will always have a dark purple color.

## Opacity

Changes the opacity of the ESP fill. The outline stays opaque for visibility; zero opacity hides both.

## Mode

### Full

Renders filled ESP boxes with a strong outline, visible through walls.

### Outline

Only renders outlined ESP boxes, visible through walls.

## Show obsidian

Shows obsidian that is placed around the bed.

## Bedwars only

Only renders ESP boxes if you are currently in a Bedwars game.
