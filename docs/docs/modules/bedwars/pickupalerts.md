# **PickupAlerts**

#### Alerts you when someone picks up a resource.

!!! Info

    This is limited by render distance for entities, by default this is `64 blocks`, however it may be more or less which will depend on the server you are currently playing on.

---

## Cooldown

This is the cooldown for alerts per player, and it includes all items. That means it will not alert for the same player sooner than what this is set at regardless of what item they pick up.

## Ping sound

Plays a sound when a player picks up a resource.

## Resources

Select resources that this will alert for.

- Iron Ingots
- Gold Ingots
- Diamonds
- Emeralds
