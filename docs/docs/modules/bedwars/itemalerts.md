# **ItemAlerts**

#### Alerts you when players hold important items.

---

## Alert

### Chat

Sends a chat message.

### Notification

Sends alert as a toast notification.

### All

Sends chat message & sends toast notification.

## Ping sound

### All

Plays a sound for all alerts.

### Important

Only plays a sound for important alerts.

**Applies to:**

- Invis Potion
- Jump Potion
- Speed Potion
- Bridge Egg
- Diamond Sword
- Iron Golem
- Bedbug
- Diamond Pickaxe
- Enchanted Bow
- Milk
- Ender Pearl
- Charlie the Unicorn

### None

Plays no sound.

## Distance

### All

Shows distance to player for all items.

### Important

Only shows distance to player for important items.

**Applies to:**

- Invis Potion
- Jump Potion
- Speed Potion
- Fireball
- Bridge Egg
- Ender Pearl
- Charlie the Unicorn

### None

Shows no distance.

## Cooldown

Adjusts the cooldown for alerts per player.
