# **FlagDetector**

#### Alerts when you potentially flag an anticheat.

---

## Alert cooldown

Controls how often this will alert when continously flagging.

!!! Tip

    Usually when the server corrects your movement this would alert several times in quick succession, so it is recommended that you use a higher cooldown if you don't want to get spammed with alerts.

## Ping sound

Plays a firework explosion sound each alert.
