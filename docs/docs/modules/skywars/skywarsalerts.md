# **SkywarsAlerts**

#### Alerts you when players hold important items.

---

## Alert

### Chat

Sends a chat message.

### Notification

Sends alert as a toast notification.

### All

Sends chat message & sends toast notification.

## Ping sound

### All

Plays a sound for all alerts.

### Important

Only plays a sound for important alerts.

**Applies to:**

- Ender Pearl
- Diamond Sword
- Knockback Rod
- Strength Potion

### None

Plays no sound.

## Cooldown

The cooldown in-between alerts for the same item, per player.

## Show distance

Shows the distance to the player in the alert message.

## Items

Select which items to alert for.

- Fire Sword
- Diamond Sword
- Knockback Sword
- Knockback Rod
- Strength Potion
- Ender Pearl
- Corrupt Pearl
- Time Warp Pearl

!!! Note

    This is based on prediction, in rare cases this may false flag because an item looks the same as what you have whitelisted.

## Nametag Icon

This will display an icon in player nametags if they ever held an important item this game.

### Enabled

Enables showing icons for players.
