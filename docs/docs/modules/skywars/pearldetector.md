# **PearlDetector**

#### Detects thrown pearls and positions.

---

## Color

Change the color of HUD element, for your own timer.

## Timer

This controls when your own timer starts counting down if you threw a time-warp pearl.

!!! Tip

    Try **On message** mode first, and if that doesn't work change to **On click** mode.

### On message

Relies on message sent by the server, the timer will be more accurate but if the server changes the message, this won't work.

### On click

This starts the timer if you hold a time-warp pearl and right-click it, this does not rely on any messages however the timer will be less accurate.

## Text scale

Change text size for your own timer.

## Ping sound

Play a sound when a pearl is thrown.

## Timer for self

Displays a timer for yourself if you throw a time warp-pearl, counting down until you get warped back.

## Position for others

Displays a box where someone will warp back to if they used a time-warp pearl.

## Thrown pearl alert

Alerts in chat if someone throws a pearl, if that pearl type is selected.

## Pearls

The type of pearl this should alert for.

- Ender Pearl
- Corrupt Pearl
- Time Warp Pearl
