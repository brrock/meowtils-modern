# **SessionStats**

#### Displays your own gamemode stats for the current instance or per game.

---

## Color

Change the color for the HUD element.

## Display

**Modes:** _Horizontal, Vertical_

Lets you adjust the way the HUD element is displayed.

## Reset

Reset current stats.

## Scale

Changes text size for the HUD element.

## Reset after game

If enabled it will automatically reset all of your stats after each game, rather than storing your stats for this session.

!!! Tip

    It is generally recommended that you keep this disabled as Hypixel already displays the stats you get each game.

## Game recap message

Sends a chat message with the stats you got last game.

## Bedwars

### Enabled

Will display your current stats when in a Bedwars game or lobby.

### Show Kills

Tracks your Bedwars kills.

### Show Final kills

Tracks how many final kills you have gotten.

### Show FKDR

Tracks your current final kill-death ratio.

_Calculation: final kills / final deaths._

### Show Earned exp

Tracks how much Bedwars experience you have gained.

## Skywars

### Enabled

Will display your current stats when in a Skywars game or lobby.

### Show Kills

Tracks your Skywars kills.

### Show Earned exp

Tracks how much Skywars experience you have gained.
