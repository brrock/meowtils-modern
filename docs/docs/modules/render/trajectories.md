# **Trajectories**

#### Shows the trajectory for projectiles you can throw.

---

## Color

Adjusts the color for the shown trajectory.

## Mode

Changes how the highlighted target will look like.

### Outline

Shows an outline for targeted block or entity.

### Full

Shows a full box for the targeted block or entity.

## Highlight target

Highlights the place that your projectile is predicted to land on, either a block or entity.

## Recolor target entity

If you are currently targeting an entity this will recolor their box to be green instead of the color you set.

!!! Tip

    This is useful for extra visibility, in situations where you need to act quickly such as when shooting a bow.

## Expand fireball hit

This increases the size of the highlighted box for targets, when throwing a fireball, since fireballs usually have some AOE (area of effect).

!!! Info

    This only applies when targeting blocks, not entities. For entities it will display the regular size like any other projectile.

## For

Toggle which items there will be a trajectory for when holding.

- Eggs
- Snowballs
- Pearls
- Fireballs
- Bows
