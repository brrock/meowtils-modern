# File Safety

Download this port only from [github.com/brrock/meowtils-modern/releases](https://github.com/brrock/meowtils-modern/releases/latest).

A Fabric mod jar has the same permissions as Minecraft. Only run jars you trust.

This build is not Notch-obfuscated (26.2 is shipped with names). There is no Lunar injector and no `.exe`. Ignore any “Meowtils installer” or Lunar JVM-argument guide — that was the old 1.8.9 distribution.
