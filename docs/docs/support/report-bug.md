# Report a Bug

File bugs on [brrock/meowtils-modern](https://github.com/brrock/meowtils-modern/issues).

## Try this first

- Remove other mods except Fabric API and Meowtils. If a conflict remains, name the other mod in the report.
- Remove every file in `meowtils/extensions/`.
- Set Hypixel language to **English**. A lot of modules parse chat and the scoreboard.
- Use a clean Prism instance: Fabric 26.2, Fabric API, Java 25, Meowtils only.
- Do not use ViaFabricPlus on the client. Server-side ViaVersion / ViaProxy only.

## What to include

- Meowtils version (Click GUI footer)
- Fabric Loader and Fabric API versions
- Latest log from the instance
- Whether the server is native 26.2 or 1.8.9-through-Via
- Exact steps
